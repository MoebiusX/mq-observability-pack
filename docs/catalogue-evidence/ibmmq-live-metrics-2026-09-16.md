## mq_prometheus (`job="ibmmq-exporter"`) — 175 names as stored in Prometheus

Taken from Prometheus rather than the raw endpoint on purpose: the exporter drains `$SYS` publications on every
Collect, so a manual curl steals them from the next scrape. All exporter series are gauges (`overrideCType: false`);
the `$SYS` "count" elements are per-interval deltas, so per-second rates are `sum_over_time(x[2m]) / 120`.

```
curl -s -G http://127.0.0.1:29090/api/v1/query --data-urlencode 'query=count by (__name__)({job="ibmmq-exporter",__name__=~"ibmmq_.*"})'
```
