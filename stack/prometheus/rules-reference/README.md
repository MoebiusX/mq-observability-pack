# stack/prometheus/rules-reference

Observogram's reference packs (`grafana`, `prometheus`) materialised for **live validation against
this lab**, which scrapes its own Grafana, Prometheus, Alertmanager, Loki and Tempo. Not part of the
MQ pack: `tools/check-rules.mjs` reads only `stack/prometheus/rules`; Prometheus loads this
directory too (`rule_files` in `stack/prometheus/prometheus.yml`, compose mount
`/etc/prometheus/rules-reference`).

Generated by `node tools/reference-packs.mjs` (`npm run refpacks` also imports the packs' boards
into Grafana's "Reference packs (generated)" folder and reports which rules produce samples and
which board panels return data). Every file names the Observogram ref and commit it came from; do
not edit, rerun the tool. `<pack>.recording.yml` is the pack's `spec.queries.recording_rules` with
`ref:slis.<id>` expanded; `<pack>.burn.yml` is the burn-rate / error-budget file Observogram
generated for the pack (`reference-packs/rules/`).
